# Perfect Guess Game 🎯

A simple command-line Python game where the user tries to guess a randomly generated number between 1 and 100.

## 🔹 Features

* Random number generation using `random` module
* User-friendly hints (higher/lower) after each guess
* Counts number of attempts taken
* Continuous loop until correct guess

## 🔹 How It Works

The program generates a random number, and the user keeps guessing until they find the correct one. After each attempt, feedback is provided to guide the next guess.

## 🔹 Tech Stack

* Python

## 🔹 Learning Outcomes

* Loops and conditional statements
* User input handling
* Basic game logic implementation
